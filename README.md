# Mihir Bhayani | Portfolio Website

A modern, responsive portfolio website showcasing the work and skills of Mihir Bhayani, a Full-Stack Developer and MCA student based in Pune, Maharashtra.

## 🚀 Features

- **Responsive Design** - Fully optimized for all screen sizes
- **Dark/Light Theme** - Toggle between themes with persistent preference
- **Interactive Elements**:
  - Preloader animation
  - Custom cursor glow effect
  - Typewriter text animation
  - Particle background effect
  - Scroll progress indicator
  - Animated gradient borders
- **Project Showcase** - Filterable project gallery with live demos and source code links
- **Contact Form** - Integrated with EmailJS for direct messaging
- **Accessibility** - Keyboard navigation and ARIA labels

## 🛠️ Technologies Used

### Frontend
- **HTML5** - Semantic markup
- **CSS3** - Custom properties (CSS variables), flexbox, grid, animations
- **JavaScript (ES6+)** - DOM manipulation, event handling, Intersection Observer API

### Libraries & APIs
- **Boxicons** - Icon library
- **Font Awesome** - Additional icons
- **Google Fonts (Poppins)** - Typography
- **EmailJS** - Contact form integration

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/mihirpatel0811/portfolio-website.git
```

2. Open `index.html` in your browser

3. For the contact form to work, configure EmailJS:
   - Replace `emailJsKey`, `emailJsService`, and `emailJsTemplate` in `script.js` with your EmailJS credentials
